# Notice

This repository provides curated supporting artifacts for the TianJi-Environ manuscript. It does not redistribute WRF-Chem, WRF/WPS, meteorological input archives, emissions inventories, observation products, or other third-party datasets that are governed by their own licenses or access terms.

The branch-result JSON files in `case_studies/` are sanitized summaries. Platform-specific paths, private working directories, and execution-environment details have been removed or replaced by public placeholders. The numerical values and evidence summaries are preserved for manuscript-level inspection.

The scripts are released for transparency and may require adaptation to local data paths, model installations, and Python environments.

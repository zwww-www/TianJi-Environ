# Diagnostic Tasks

This directory contains three representative post-processing and lightweight diagnostic-task examples used in the manuscript system-level analysis.

- `sa_01_mda8_o3_peak`: MDA8 ozone peak identification.
- `sa_03_pm25_episode`: PM2.5 episode diagnosis and pollution-centre identification.
- `sa_05_o3_meteorology_covariation`: O3--meteorology co-variation diagnosis.

The examples are included as diagnostic outputs and summarized tables rather than as claims of independent atmospheric mechanism validation.
